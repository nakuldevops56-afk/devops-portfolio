# Linux Server Health Check

## Project Overview

This project contains a Bash script that checks basic Linux system health information.

## Features

- Displays the server hostname
- Shows the current date and time
- Reports system uptime
- Displays memory usage
- Checks root filesystem disk usage

## Requirements

- Linux operating system
- Bash shell
- Standard Linux utilities

## How to Run

Clone the repository:

```bash
git clone https://github.com/nakuldevops56-afk/devops-portfolio.git

Navigate to the project directory:

cd devops-portfolio


Make the script executable:

chmod +x health_check.sh



Run the health check:

./health_check.sh
